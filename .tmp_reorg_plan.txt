Proposed folder layout under src:

src/
  core/        - system-level and main app files (main.c, main.h, stm32f103xx_CMSIS.*)
  drivers/     - peripheral drivers (i2c_drive.c/h, SPI2.c/h, HAL_GPIO.c/h, port_ini.c, stm32f1_rtc.c/h)
  gfx/         - display drivers and graphics (ILI9341.*, ili9341_*.c/h)
  images/      - large image data files (image_*.c)
  fonts/       - font sources (Font_34x37.c, Font_34x37.h, Fonts.c, Font1_34x37.c)
  app/         - application-specific code (gp_drive.c/h, encoder.c/h, Filtrs.c/h, timestamp.c/h, rtc_unit.h)
  utils/       - misc utilities (ADC.c/h, timestamp.c/h)
