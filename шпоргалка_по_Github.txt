Команда	в терминале
git status	Посмотреть изменения
git add .	Подготовить изменения
git commit -m "..."	Сохранить версию
git push	Отправить на GitHub
git pull	Получить изменения с GitHub

//*******************************************

Чтобы сохранить изменения на GitHub, достаточно выполнить три команды:
git add .
git commit -m "Описание изменений"
git push
