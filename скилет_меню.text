Скелет меню стиральной машины с TFT 240×320 и энкодером
Общие принципы
Экран ориентирован вертикально (240×320), что позволяет 
отображать 4–6 строк текста или пунктов меню с достаточным шрифтом.

Управление: энкодер (поворот для перемещения курсора, 
нажатие для выбора/подтверждения), кнопка энкодера также может 
использоваться для возврата (долгое нажатие) или вызова контекстного меню.

Навигация строится на линейных списках с циклическим скроллингом.

Текущий пункт выделяется инверсией, рамкой или изменением цвета.

Иерархия меню
1. Стартовый экран (после включения / в режиме ожидания)
Крупный индикатор времени / «Готов к работе»

Подсказка: «Поверните для выбора программы»
При повороте энкодера сразу переходим в главное меню программ.

2. Главное меню — выбор программы стирки
Список программ (отображается 4–5 пунктов):

Хлопок

Синтетика

Деликатная

Шерсть

Быстрая 15'

Полоскание + Отжим

Отжим

... (другие программы)

При нажатии на программу — вход в экран настроек программы.

3. Экран настроек выбранной программы
Вертикальный список параметров для текущей программы:

Температура (текущее значение, например, 40°C)

Отжим (об/мин, например, 800)

Доп. функции (например, «Предварительная стирка: Нет»)

Время стирки (отображается автоматически, не редактируется)

➜ Старт

⬅ Назад (возврат в главное меню)

Взаимодействие:

Поворот энкодера — перемещение по пунктам.

Нажатие на пункте с параметром (температура, отжим, доп. функция)
открывает экран выбора значения.

Нажатие на «Старт» запускает программу (переход к экрану выполнения).

Нажатие на «Назад» возврат в главное меню.

4. Экран выбора значения (для температуры, отжима и т.п.)
Список возможных значений:

Температура: Холодная, 20°, 30°, 40°, 60°, 90°

Отжим: Без отжима, 400, 600, 800, 1000, 1200 (зависит от модели)

Доп. функции: вкл/выкл (список из двух пунктов)

Поворот — выбор значения, нажатие — подтверждение и возврат к экрану настроек.

5. Экран выполнения стирки
Название программы

Оставшееся время (крупно)

Текущий этап (стирка, полоскание, отжим)

Индикатор прогресса (полоса)

Кнопка «Пауза» / «Отмена» (при нажатии открывается диалог подтверждения)

Долгое нажатие кнопки энкодера — возврат в главное меню (с остановкой программы, если требуется подтверждение).

6. Меню настроек машины (доступное, например, через долгое нажатие из главного меню или отдельный пункт в конце списка программ)
Список:

Язык (Русский / English / ...)

Яркость (уровни)

Звук (Вкл / Выкл)

Сервисное меню (для диагностики, скрыто кодом)

Навигация аналогична: выбор → изменение значения (список или регулятор).

Примерный алгоритм навигации (псевдокод)
text
переменная currentScreen = MAIN_MENU
переменная selectedIndex = 0
массив menuItems = [...] // для текущего экрана

loop {
    отобразить currentScreen с подсветкой selectedIndex
    при повороте энкодера {
        selectedIndex = (selectedIndex + шаг) % длина_списка
    }
    при коротком нажатии {
        если currentScreen == MAIN_MENU:
            currentScreen = PROGRAM_SETTINGS(menuItems[selectedIndex])
            selectedIndex = 0
        иначе если currentScreen == PROGRAM_SETTINGS:
            если выбран параметр:
                currentScreen = VALUE_SELECTOR(параметр)
                selectedIndex = индекс текущего значения
            иначе если выбран "Старт":
                currentScreen = WASH_RUNNING
            иначе если выбран "Назад":
                currentScreen = MAIN_MENU
        иначе если currentScreen == VALUE_SELECTOR:
            сохранить выбранное значение
            currentScreen = PROGRAM_SETTINGS
        иначе если currentScreen == WASH_RUNNING:
            показать диалог паузы/отмены (новый экран или всплывашка)
    }
    при долгом нажатии (если поддерживается) {
        если currentScreen не MAIN_MENU:
            currentScreen = MAIN_MENU // быстрый возврат на главную
        иначе:
            currentScreen = SETTINGS_MENU
    }
}
Особенности реализации
Для экономии места можно использовать иконки рядом с текстом (например,
капля для температуры, спираль для отжима).

При отображении списка значений показывать текущее выбранное значение и шкалу 
(если много вариантов — использовать полосу прокрутки).

Подтверждение опасных действий (например, отмена стирки) через диалог: 
«Отменить? Да / Нет».

Этот скелет обеспечивает интуитивное управление одним энкодером и укладывается 
в ограничения экрана 240×320.
